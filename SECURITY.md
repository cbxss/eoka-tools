# Security Policy

## Supported Versions

Security fixes are handled on the latest released crate and binary versions.

## Reporting a Vulnerability

Please report security issues privately through GitHub Security Advisories:

https://github.com/shrimp-software/eoka-tools/security/advisories/new

Do not open a public issue for a suspected vulnerability.

Include the affected crate or binary, version, operating system, and a minimal
reproduction when possible.
